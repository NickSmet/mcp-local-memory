# Work in Progress

This folder contains **drafts, design exploration, and archived historical notes**.

## Conventions

- Active design work should live under a feature folder: `docs/work-in-progress/<feature>/`
- Historical “one-off” notes should be moved into `docs/work-in-progress/_archive/`
- Stable, user-facing behavior should be promoted into:
  - Co-located module specs: `src/**/SPEC.md`
  - Feature quick refs: `docs/features/*.md`

## Index

| Path | Purpose | Status |
|------|---------|--------|
| `docs/work-in-progress/_archive/` | Archived historical notes (kept only if still useful) | ✅ Complete |
